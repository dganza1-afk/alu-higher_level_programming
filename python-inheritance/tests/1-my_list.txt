The ``1-my_list`` module
========================

Using ``MyList``
----------------

Import the class:

    >>> MyList = __import__('1-my_list').MyList

MyList is a subclass of list:

    >>> issubclass(MyList, list)
    True

An empty list prints as an empty list:

    >>> my_list = MyList()
    >>> my_list.print_sorted()
    []

Printing sorted does not change the original list:

    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]
    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

An already sorted list stays the same:

    >>> MyList([1, 2, 3]).print_sorted()
    [1, 2, 3]

A list in reverse order:

    >>> MyList([5, 4, 3, 2, 1]).print_sorted()
    [1, 2, 3, 4, 5]

Negative numbers and duplicates:

    >>> MyList([3, -1, 0, -7, 3]).print_sorted()
    [-7, -1, 0, 3, 3]

A single element:

    >>> MyList([98]).print_sorted()
    [98]

print_sorted returns a new list, not a MyList:

    >>> my_list = MyList([2, 1])
    >>> my_list.print_sorted()
    [1, 2]
    >>> type(my_list) is MyList
    True

Calling it with an argument fails:

    >>> my_list.print_sorted(1)  # doctest: +IGNORE_EXCEPTION_DETAIL
    Traceback (most recent call last):
    ...
    TypeError: print_sorted() takes 1 positional argument but 2 were given
